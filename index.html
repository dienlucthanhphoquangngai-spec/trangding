Kết nối Google Sheet (làm một lần)
  1. Mở Google Sheet của bạn, chọn Tiện ích mở rộng rồi Apps Script.
  2. Xóa code cũ, dán đoạn code bên dưới rồi lưu.
  3. Chọn Triển khai rồi Ứng dụng web. Thực thi với quyền “Tôi”, quyền truy cập “Bất kỳ ai”. Cấp quyền khi Google hỏi.
  4. Sao chép URL kết thúc bằng /exec, dán vào ô dưới và bấm Lưu và đồng bộ.
const SS='1hFE4Z73EiCfAIQc2c09WZkaU6LrB_dg0UvG0X3Lk3NE';
const H=['id','thoiGian','coin','loai','gia','soTienUSDT','soLuong','idMua','loiLo','loiLoPct','ketQua','duBao1Ngay','duBaoTheoKhung'];
function sh(){const s=SpreadsheetApp.openById(SS);let t=s.getSheetByName('GiaoDich');if(!t){t=s.insertSheet('GiaoDich');t.appendRow(H)}return t}
function doPost(e){const r=JSON.parse(e.postData.contents);sh().appendRow(H.map(k=>r[k]??''));return ContentService.createTextOutput('ok')}
function doGet(){const v=sh().getDataRange().getValues(),h=v.shift();
  return ContentService.createTextOutput(JSON.stringify(v.map(r=>Object.fromEntries(h.map((k,i)=>[k,r[i]]))))).setMimeType(ContentService.MimeType.JSON)}

Bấm vào một dòng để xem chi tiết khung đó. Dữ liệu tự cập nhật mỗi 30 giây.

Trang này chỉ nhận diện mô hình nến theo quy tắc kỹ thuật và không phải lời khuyên đầu tư. Mô hình nến có thể sai, nhất là khi thị trường biến động mạnh. Luôn đặt cắt lỗ và quản lý vốn. TradingView không có API công khai để lấy dữ liệu, nên trang lấy giá từ API công khai của Binance, cùng nguồn với biểu đồ BINANCE trên TradingView.
